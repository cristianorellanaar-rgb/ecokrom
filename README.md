# EcoKrom®

Sitio web informativo de **EcoKrom®** (Tecnología del futuro.): pinturas y tintas fotoluminiscentes de fabricación nacional para gráfica, construcción y arte. Marca registrada.

Sitio estático en un solo archivo (`index.html`), publicado con GitHub Pages.

## Qué incluye

- Interruptor **Día / Noche** que cambia todo el sitio y la ilustración del hero
- Comparadores deslizables con fotos reales (maqueta y planta industrial) y video de la maqueta
- Secciones: Producto, Cómo funciona, Aplicaciones por rubro (Gráfica, Construcción, Arte y diseño), Beneficios, Ficha técnica, Trabajos, Preguntas frecuentes y Contacto
- Calculadora de material (m², kg de base y de pintura) con envío del cálculo por WhatsApp
- Calculadora de ahorro frente a luminarias (kWh y CO₂ por año)
- Formulario de contacto que arma el mensaje y lo abre en WhatsApp
