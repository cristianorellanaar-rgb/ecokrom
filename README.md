# EcoKrom®

Sitio web informativo de **EcoKrom®** (Tecnología del futuro.), pintura fotoluminiscente de fabricación nacional. Marca registrada.

Sitio estático en un solo archivo (`index.html`), publicado con GitHub Pages.

## Qué incluye

- Interruptor **Día / Noche** que cambia todo el sitio y la ilustración del hero
- Comparador deslizable día/noche
- Secciones: Producto, Cómo funciona, Aplicaciones, Beneficios, Ficha técnica, Obras, Preguntas frecuentes y Contacto
- Calculadora de material (m², kg de base y de pintura) con envío del cálculo por WhatsApp
- Calculadora de ahorro frente a luminarias (kWh y CO₂ por año)
- Formulario de contacto que arma el mensaje y lo abre en WhatsApp

## Pendiente con el cliente
